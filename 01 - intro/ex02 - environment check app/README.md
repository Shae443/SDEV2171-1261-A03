# Lesson 02 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `setup-checklist.md` during class.
2. Use `troubleshooting-checklist.md` if setup fails or stalls.
3. Record your current state in `setup-status-tracker.md` if instructed.
4. Use the verification app from `example/` only if the instructor directs you to it.
5. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The checklist and live setup attempt come first.
