# Lesson 06 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `navigation-build-checklist.md` during class.
2. Check `starting-state-reference.md` if you are unsure whether your project is ready.
3. Use `screen-flow-reference.md` and `starter-snippets.md` while building the route structure.
4. Use `troubleshooting-checklist.md` if the app or flow breaks.
5. Record your current state in `navigation-status-tracker.md` if instructed.
6. Use the reference path in `example/` only if the instructor directs you to inspect it.
7. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The guided navigation activity and support references come first.
