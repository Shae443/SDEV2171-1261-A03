# Lesson 05 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `guided-build-checklist.md` during class.
2. Check `starting-state-reference.md` if you are unsure whether your project is ready.
3. Use `starter-snippets.md` and `styling-reference.md` while making style changes.
4. Use `troubleshooting-checklist.md` if the layout or app breaks.
5. Use the reference app in `example/` only if the instructor directs you to it.
6. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The guided styling activity and support references come first, and the exercise is the follow-up task.
